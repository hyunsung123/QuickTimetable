# 겹침 금지·빈 공간 자동 맞춤·26px 시간표

> 이전 작업 기록입니다. 26px 행·배치 정책은 유지하며, 2026-11-12부터 자동 적용은 [수동 시간표 불러오기](MANUAL_WEEK_IMPORT.md)로 대체합니다.

2026-11-10 작업. 기준 커밋은 GitHub `main`과 같은 `4c438a7`이며 기존 `mobile` 프로젝트를 수정했습니다. 의존성, SQLite 스키마/버전, 기본 적용 시작일 및 초기화 정책은 변경하지 않습니다.

## 배치 정책

충돌 구간은 `[startMinute, endMinute)`입니다. 날짜 일정은 같은 날짜끼리, 기본 시간표는 같은 `presetId`·요일끼리 비교합니다. 자신의 ID는 비교에서 제외하며 다른 날짜·시간표에는 영향을 주지 않습니다. 정확히 맞닿는 일정은 허용합니다.

| 작업 | 시작 위치가 점유됨 | 시작은 비어 있고 끝만 겹침 |
|---|---|---|
| 블록 이동 | 미리보기 붉은 반투명 → 저장 없이 복귀 | 다음 블록까지 축소해서 저장 |
| 복사·붙여넣기 | 오류 후 취소 | 다음 블록까지 축소, 새 ID로 저장 |
| 직접 생성·편집 | 겹침 오류, 입력값 유지 | 겹침 오류, 입력값 유지 |
| 시간표 불러오기 | 원본 내부 겹침이 있으면 전체 취소 | 동일 |
| 공유 경계선 | 기존 인접 두 블록 계산 유지 | 빈 공간을 지나 접촉하면 기존 공유 경계선 계산 유지 |

`fitInFreeSpace()`는 UI와 독립된 순수 함수입니다. 30분으로 스냅된 새 시작 시각이 다른 블록 내부인지 먼저 확인합니다. 비어 있다면 이후의 가장 가까운 블록 시작(없으면 1440)까지의 길이를 구해 `min(원래 길이, 빈 공간 길이)`로 정합니다. 결과는 30분 이상이어야 합니다. 예: 15:00–17:00을 12:00으로 이동하고 다음 블록이 13:00이면 12:00–13:00으로 저장합니다. 23:00에 놓은 3시간 블록은 24:00까지 1시간으로 줄입니다.

드래그 세션은 최초 일정 목록과 길이를 보관합니다. 짧은 공간을 거쳐 넓은 공간으로 이동하면 최초 길이를 다시 사용하며, 이전 미리보기의 줄어든 길이를 누적하지 않습니다. 손가락 위치는 연속으로 따라가고 저장 시간은 30분 단위입니다. 미리보기에서 높이와 시간을 표시하며, 정상 해제 시 스프링으로 스냅 위치에 정착합니다. 실패·취소 시 원래 위치와 높이로 돌아옵니다. 점유된 이동에는 DB 쓰기를 요청하지 않습니다. 해제 직전 최신 화면 데이터로 재검사하고 DB에서도 다시 검사합니다.

Repository의 검사와 쓰기, 주 기록, 반환 스냅샷은 같은 `BEGIN IMMEDIATE` 트랜잭션 안에서 처리합니다. 생성/편집은 임의로 시간을 줄이지 않습니다. 붙여넣기는 트랜잭션에서 읽은 최신 데이터로 맞춥니다. 불러오기 실패 시 대상 삭제나 새 시간표 생성도 함께 롤백합니다. 동시 작업은 기존 큐로 직렬화됩니다.

## 기존 중복 데이터

- 앱 시작·마이그레이션 시 기존 겹친 행을 변경하지 않습니다. 새 DB 제약으로 예전 데이터를 지우거나 테이블을 재작성하지 않습니다.
- `eventLanes()`와 lane/lanes 렌더링을 제거했습니다. 모든 블록은 `dayWidth - 4`의 같은 열 너비를 사용합니다.
- 같은 위치에서 가려진 블록도 편집할 수 있도록 시간표 위에 겹친 일정 목록을 표시합니다. 기존 제목·색상 편집은 시간을 그대로 둔 경우 허용하며, 시간을 바꾸면 충돌 없는 위치로 지정해야 합니다.
- 겹친 원본을 불러오거나 기본 시간표로 새 주에 복제하는 작업은 전체 취소하고 원본 수정을 안내합니다. 일부 블록만 선택해서 복사하거나 임의로 축소하지 않습니다. 실패 시 주 초기화 기록도 생성되지 않아 수정 후 다시 시도할 수 있습니다.
- 기존 공유 경계선 순수 함수 `resizeBoundary()`는 변경하지 않았습니다. 모호한 중복 구간에서는 기존처럼 조절을 제한합니다.

## 행 높이와 터치

| 항목 | 이전 | 변경 후 |
|---|---|---|
| 30분 행 | 44px | 26px (약 41% 축소) |
| 하루 격자 | 2112px | 1248px |
| 30분 블록 | 계산 높이 42px, 최소 32px | 24px, 행을 넘는 최소 높이 제거 |
| 손잡이 | 위아래 전체 너비 각 12px | 오른쪽 위/아래 각 10px, 블록 내부에 한정 |
| 30분 제목 | 큰 블록과 같은 배치 | 한 줄, 9px/확대 11px, 12px 줄 높이 |
| 1시간 이상 | 높이에 따라 시간 생략 | 제목과 시간 표시, 확대 시 시간 한 줄 |
| 08:00 초기 스크롤 | 704px | 416px |

손잡이는 2px 흰 선을 유지하고 터치 영역은 그보다 크게 잡되 블록 외부로 확장하지 않습니다. 30분 블록 안에서 위/아래 영역이 겹치지 않고 왼쪽은 전체 높이의 편집·이동 영역으로 남습니다. 확대 편집은 열 너비를 넓힙니다. 작은 블록의 실제 손가락 조작감은 iPhone 확인 대상입니다. 블록 글자는 공간에 맞춰 줄 수와 글꼴 확대 상한을 설정하며 접근성 레이블에는 전체 제목과 시간이 있습니다.

눈금·가로선·세로 스크롤 동기화·제스처 스냅·미리보기는 공통 `slotHeight`를 사용합니다. 주간 계획, 기본 시간표 편집, 읽기 전용 불러오기 미리보기에 같은 격자가 적용됩니다.

## 검증

자동 테스트 109/109 통과. 기존 기본 시간표 적용 시작일·과거/빈 주 보존, SQLite 마이그레이션·재시작, 전체 초기화와 롤백, 클립보드·공유 탭·다중 시간표·불러오기 및 공유 경계선 테스트도 포함합니다. TypeScript·ESLint·Expo 의존성 검사를 통과했습니다. 추가로 `expo export --platform ios --platform android --platform web`도 성공했으며 iOS 1725개·Android 1833개·웹 1400개 모듈을 번들링했습니다.

UI 테스트는 실제 React 컴포넌트와 훅을 실행하지만 네이티브 레이아웃/제스처 및 스프링 시간 진행은 대역입니다. 픽셀 값과 콜백 연결을 검증하며 iPhone의 실제 손가락 인식과 애니메이션을 대신하지 않습니다. 연결 가능한 브라우저가 없어 별도 웹 화면 캡처는 수행하지 않았습니다. 개발 중 실제 사용자 DB의 초기화는 실행하지 않았습니다.

iPhone Expo Go 확인 항목은 [실기기 체크리스트](TOUCH_TESTS.md)의 겹침 방지·빈 공간 자동 맞춤·26px 행·공유 경계선 항목을 따릅니다.
